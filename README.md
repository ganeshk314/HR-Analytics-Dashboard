# 👥 HR Analytics Dashboard

An interactive **Power BI dashboard** designed to analyze workforce performance, employee attrition, and key HR metrics. The dashboard transforms raw HR data into actionable insights through dynamic visualizations, enabling organizations to make informed, data-driven decisions.

---

![Dashboard Preview](Images/HR-Dashboard.gif)

## 🚀 Project Overview

The **HR Analytics Dashboard** provides a comprehensive view of an organization's workforce by tracking employee demographics, attrition trends, experience, salary distribution, and performance metrics. It helps HR professionals identify patterns, monitor key indicators, and support strategic workforce planning.

## 📊 Dashboard Metrics

| KPI | Description |
|------|-------------|
| Total Employees | Total workforce count |
| Active Employees | Current active employees |
| Attrition Count | Number of employees who left |
| Attrition Rate | Percentage of employee attrition |
| Average Age | Average employee age |
| Average Salary | Average salary across employees |
| Average Experience | Average years of experience |
